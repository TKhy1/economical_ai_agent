CampusWallet · 安装说明

20.8 MB仅 arm64 设备
Android 8.0+minSdk 26
已实测荣耀 400 Pro / Android 16

一 · 装到手机

  1. 把 CampusWallet-1.0.0-arm64.apk 传到手机（USB / 微信文件传输助手 / 网盘）。
  2. 用「文件管理」点开 APK。
  3. 按提示允许「安装未知应用」「已了解此应用未经检测」，继续安装。

二 · 荣耀 / MagicOS 必看

若安装界面连「安装」按钮都没有：设置 → 系统和更新 → 纯净模式 → 关闭「增强防护」，再点一次 APK。

三 · 首次启动

  1. 点桌面图标 CampusWallet（蓝底白色 ¥），约 0.5 秒进入。
  2. 首次是空账本，界面默认英文：底部 Settings → LANGUAGE → 中文 可切换。
  3. 想看效果：Settings → THIS DEVICE → Load demo data，灌入一套演示账目。

四 · 接入 AI（可选）

  1. Settings → THIS DEVICE → Connect the AI agent
  2. 粘贴 DeepSeek Key（sk-...）
  3. 点 测试连接，出现 "ok": true 才算通
  4. 点 保存并应用，聊天页徽标变为「DeepSeek 已接入」
Key 只存在本机应用私有目录，不随 APK 分发；不填 Key 也能用，对话自动走内置规则引擎。

五 · 数据与导出

账本数据库应用私有目录（文件管理器不可见）
导出的 CSV下载 / CampusWallet /，每次导出一个文件，可系统分享
导出入口Settings → THIS DEVICE → Export ledger CSV

六 · 卸载与清理

设置 → 应用 → 应用管理 → CampusWallet → 卸载 （或 adb uninstall com.campuswallet.demo）

  • 会一并删除：APK、账本、AI Key、Python 运行时解压文件。
  • 不会自动删除：导出过的 CSV，请手动删除「下载/CampusWallet」文件夹。
